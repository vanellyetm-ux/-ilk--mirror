# Land of Mu — Render and Release Bridge

The $ilk Mirror connects composition provenance to actual rendered outputs and the separate public release process.

## Destinations

- Private production repository: https://github.com/Vanellye/the-land-of-mu
- Production main stream: https://github.com/Vanellye/the-land-of-mu/blob/main/MAIN-STREAM.md
- Composition/data library: https://github.com/Vanellye/DataEnvelopeMint
- Public-facing music index: https://github.com/vanellyetm-ux/Lumi/blob/main/MUSIC-MAIN-STREAM.md

## Evidence chain

SOURCE_SKETCH → COMPOSITION_ENVELOPE → ARRANGEMENT_REVISION → WAV_MIDI_RENDER → TECHNICAL_VALIDATION → LISTENING_REVIEW → RIGHTS_REVIEW → HUMAN_RELEASE_APPROVAL → PUBLIC_RELEASE

## Required render receipt

Each render should record the source arrangement and revision, renderer and version, render settings, WAV and MIDI filenames, byte sizes, SHA-256 hashes, technical checks, and limitations.

## Separation of authority

The mirror records lineage and evidence; it does not publish. The Land of Mu produces files; it does not authorize public release by itself. Lumi indexes only approved public release destinations. Private research, lyrics, stems, and unreleased masters remain private unless separately approved.
